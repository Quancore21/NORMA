# Параметры winws в стратегиях

Справочник создаётся `tools/gen_strategies.py` из `app/core/options.txt` и реального использования параметров в стратегиях zapret.
Правьте описания в `app/core/options.txt`, а не этот файл. Самопроверка NORMA следит, чтобы каждый параметр стратегий был описан.

Колонка «Стратегий» показывает, в скольких из 22 стратегий zapret параметр встречается.

## Захват трафика

| Параметр | Что делает | Стратегий |
|---|---|---|
| `--wf-tcp` | Порты TCP, которые драйвер WinDivert перехватывает для обработки (фильтр захвата). | 22 |
| `--wf-udp` | Порты UDP, которые драйвер WinDivert перехватывает для обработки (фильтр захвата). | 22 |

## Выбор трафика (профили)

| Параметр | Что делает | Стратегий |
|---|---|---|
| `--filter-tcp` | Профиль применяется к TCP-соединениям на этих портах. | 22 |
| `--filter-udp` | Профиль применяется к UDP-трафику на этих портах. | 22 |
| `--filter-l3` | Профиль применяется только к указанной версии IP (например ipv4). | 1 |
| `--filter-l7` | Профиль применяется только к указанному протоколу прикладного уровня: discord, stun, quic, unknown. | 22 |
| `--new` | Разделитель: дальше начинается следующий профиль со своими правилами. | 22 |

## Списки доменов и адресов

| Параметр | Что делает | Стратегий |
|---|---|---|
| `--hostlist` | Применять только к доменам из файла. | 22 |
| `--hostlist-exclude` | Не применять к доменам из файла. | 22 |
| `--hostlist-domains` | Применять только к перечисленным доменам (список прямо в параметре). | 21 |
| `--hostlist-exclude-domains` | Не применять к перечисленным доменам (список прямо в параметре). | 1 |
| `--ipset` | Применять только к IP-адресам и сетям из файла. | 22 |
| `--ipset-exclude` | Не применять к IP-адресам и сетям из файла. | 22 |

## Десинхронизация

| Параметр | Что делает | Стратегий |
|---|---|---|
| `--dpi-desync` | Режим десинхронизации: как именно сбить с толку систему DPI (fake, multisplit, multidisorder, fakedsplit, hostfakesplit и другие, через запятую). | 22 |
| `--dpi-desync-repeats` | Сколько раз повторять отправку поддельных пакетов. | 22 |
| `--dpi-desync-fooling` | Способ сделать поддельный пакет невидимым для сервера, но видимым для DPI: badseq (неверный порядковый номер), ts (неверная метка времени), md5sig (лишняя опция MD5), badsum (неверная контрольная сумма). | 17 |
| `--dpi-desync-cutoff` | Сколько пакетов соединения обрабатывать (n2: первые два от клиента), дальше трафик идёт как обычно. | 22 |
| `--dpi-desync-any-protocol` | Применять приём к любому протоколу, а не только к распознанным TLS и HTTP. | 22 |
| `--dpi-desync-badseq-increment` | На сколько сдвигать порядковый номер при приёме badseq. | 5 |

## Разрез и перекрытие

| Параметр | Что делает | Стратегий |
|---|---|---|
| `--dpi-desync-split-pos` | Позиции, в которых данные разрезаются: числа от начала, а также маркеры вроде midsld (середина домена второго уровня). | 12 |
| `--dpi-desync-split-seqovl` | Перекрытие сегментов (seqovl): первый сегмент сдвигается назад на указанное число байт, перекрытие заполнено шаблоном, которое сервер отбрасывает. | 10 |
| `--dpi-desync-split-seqovl-pattern` | Чем заполнено перекрытие seqovl (файл с данными). | 10 |
| `--dpi-desync-fakedsplit-pattern` | Байты-заполнитель для режима fakedsplit. | 1 |
| `--dpi-desync-hostfakesplit-mod` | Параметры режима hostfakesplit: host=имя сайта для подделки, altorder=1 меняет порядок отправки. | 6 |

## Содержимое поддельных пакетов

| Параметр | Что делает | Стратегий |
|---|---|---|
| `--dpi-desync-fake-tls` | Содержимое поддельного TLS ClientHello: файл .bin или шаблон. | 11 |
| `--dpi-desync-fake-tls-mod` | Изменения в поддельном ClientHello: rnd (случайные байты), dupsid (копия session id), sni=имя (подставить имя сайта). | 7 |
| `--dpi-desync-fake-http` | Содержимое поддельного HTTP-запроса или пакета (файл .bin). | 16 |
| `--dpi-desync-fake-quic` | Содержимое поддельного пакета QUIC Initial (файл .bin). | 22 |
| `--dpi-desync-fake-unknown` | Содержимое поддельного пакета для нераспознанного TCP-протокола (файл .bin). | 15 |
| `--dpi-desync-fake-unknown-udp` | Содержимое поддельного пакета для нераспознанного UDP-протокола (файл .bin). | 22 |
| `--dpi-desync-fake-discord` | Содержимое поддельного пакета для обнаружения голосового трафика Discord (файл .bin). | 22 |
| `--dpi-desync-fake-stun` | Содержимое поддельного пакета STUN (файл .bin). | 22 |
