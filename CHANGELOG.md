# Журнал изменений

Версии нумеруются как `0.X`: 0.8, 0.9, 0.10, 0.11 и так далее (части сравниваются как числа).

## 0.9
- Удалён замер скорости видео через `yt-dlp` (меню, клавиша `S`, загрузка `yt-dlp`, бенчмарк, отчёт Доктора, замер в собственном движке).
  Причина: на реальных данных скорость у всех стратегий одинакова (1,31 Мбит/с): это потолок самой ссылки, а не свойство стратегии.
- Исправлен CI: скрипты в workflow были с кириллицей и ломались в Windows PowerShell 5.1 (кодировка ANSI); теперь они только на ASCII.
- Исправлен `tools/gen_strategies.py`: падал при выводе кириллицы в консоль с кодировкой не UTF-8 (так на Windows в CI).
- Новый `tools/publish.ps1`: публикация версии одной командой (копирование в клон, самопроверка, коммит, пуш, тег; режим `-SyncOnly` для GitHub Desktop).

## 0.8
- Бенчмарк стал устойчивым к шуму: годная стратегия проверяется трижды (стабильность и медиана времени), результаты в пределах 15% считаются равными.
  Причина: в реальных журналах разница между стратегиями в сотые доли секунды была случайной.
- Замер скорости видеопотока (`yt-dlp` + `curl.exe`): участвует в бенчмарке; клавиша `S` в рабочем окне делает разовый замер; загрузка `yt-dlp` из меню.
- В журнале бенчмарка показывается оставшееся время; неподошедшие стратегии помечены «не подошла» вместо «ЛОМАЕТ».
- При конфликте записываются параметры запуска уже работающих `winws` и `goodbyedpi`; то же в отчёте Доктора.
- `VERSION` как единственный источник номера версии.
- Репозиторий для GitHub: README (рус. и англ.), MIT-лицензия, `THIRD_PARTY_NOTICES.md` с контрольными суммами, CONTRIBUTING, SECURITY,
  шаблоны обращений, CI на Windows (проверка синтаксиса PowerShell, самопроверка, сверка генератора), автосборка релизов по тегу.

## 0.7
- Новая структура архива: `vendor\zapret` (оригинал), `app` (код), `strategies`, `data`, `docs`, `tools`.
- Исправлено: в стратегиях «FAKE TLS AUTO» символ `^!` из .bat передавался в winws как есть; теперь экранирование .bat снимается.
- 34 «тонкие» стратегии для YouTube (`strategies\norma`), создаются `tools\gen_strategies.py` из правил upstream.
- Пользовательские стратегии: `strategies\user\*.args`.
- Бенчмарк: все стратегии, победитель по числу открытых сайтов и скорости ответа, результат в `data\ranking.json`.
- Память по сетям: для каждой сети (имя подключения + шлюз) запоминается своя рабочая стратегия; при смене сети подбор запускается сам.
- Доктор: диагностика (права, файлы и подпись драйвера, конфликты, VPN, DNS, IPv6, интернет, запись в data).
- Фоновый режим и автозапуск при входе (задача планировщика с высшими правами).
- Журналы в `data\logs` с ротацией; свои цели проверки в `data\targets.user.txt`.
- `tools\selftest.ps1`: самопроверка разбора стратегий и памяти по сетям.
