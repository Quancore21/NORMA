# NORMA

**Node for Obfuscated Routing and Masked Access**

Автоматический подбор обхода замедления YouTube (и Discord) на Windows. Работает на движке zapret (`winws`).

## Что это

Готовые сборки zapret требуют подбирать стратегию вручную: у каждого провайдера работает что-то своё, а то, что работало вчера, сегодня может перестать.
NORMA делает это сама:

- замеряет, что **реально** не открывается без обхода, и трогает только это;
- перебирает стратегии и берёт первую, которая всё открывает и **ничего не ломает** из того, что и так работало;
- следит за работой и **меняет стратегию**, когда она перестала помогать или сменилась сеть;
- умеет сравнивать стратегии между собой по стабильности и времени ответа (бенчмарк).

Написана на PowerShell 5.1 и не требует установки. Из изменений системы: на время работы загружается драйвер WinDivert и включаются
TCP timestamps (они нужны части стратегий, так делает и оригинальный zapret). Файл `hosts` NORMA не трогает.

## Быстрый старт

1. Скачайте архив из [Releases](https://github.com/Quancore21/NORMA/releases/latest) и распакуйте в папку **без кириллицы** в пути, например `C:\NORMA`.
2. Включите Secure DNS (DNS через HTTPS) в браузере или в настройках сети Windows 11.
3. Запустите `NORMA.bat` и согласитесь на права администратора.
4. Выберите пункт **1**. Окно должно оставаться открытым; любая клавиша выключает обход.

Требования: Windows 10 (1803 и новее) или 11, 64 бита.

## Возможности

| | |
|---|---|
| **Автоподбор** | Замер без обхода, перебор стратегий, контроль «не ломает ли остальное». Для знакомой сети сначала пробуется то, что в ней работало раньше |
| **Бенчмарк** | Все стратегии, каждая годная проверяется трижды (стабильность, медиана времени). Результаты в пределах 15% считаются равными, шум не выдаётся за преимущество |
| **Сторож** | Каждые 45 секунд проверяются нужные сайты и сеть; при деградации подбирается другая стратегия |
| **Память по сетям** | Дом, работа, кафе: для каждой сети запоминается своя стратегия |
| **Фон и автозапуск** | Работа без окна, запуск при входе в Windows (задача планировщика) |
| **Доктор** | Диагностика: права, файлы и подпись драйвера, конфликты, VPN, DNS, IPv6; отчёт копируется в буфер |
| **Свои стратегии** | Положите `*.args` или готовый `.bat` из другой сборки zapret в `strategies/user`, и стратегия попадёт в перебор |
| **Понятные стратегии** | В списке у каждой стратегии одна строка о том, что она делает (режим, подделка, разрез, перекрытие). Справочник: [docs/OPTIONS.md](docs/OPTIONS.md) |
| **Без лишних проверок** | Стратегии с одинаковым правилом для YouTube не проверяются повторно, если оно уже не сработало: подбор быстрее |
| **Игровой фильтр и IPSet** | Игровой фильтр zapret (выкл, TCP и UDP, только TCP, только UDP) и режимы IPSet (none, any, loaded) переключаются из меню |
| **Обновления** | Проверка новой версии NORMA и оригинала, обновление списков доменов и IPSet. Файлы сначала скачиваются и проверяются все вместе, потом заменяются с резервной копией; при сбое всё откатывается |
| **Аккуратность** | NORMA останавливает только свои процессы `winws`, возвращает TCP timestamps при выходе, Доктор сверяет контрольные суммы всех файлов `bin` |
| **Тонкие стратегии** | 34 готовые стратегии только для YouTube/Google, остальной трафик они не затрагивают |

## Как это работает

```
замер без обхода ──► перебор стратегий ──► первая подходящая ──► сторож
 (что заблокировано)   (winws + проверка)    (открывает нужное,   (здоровье сайтов,
                                              не ломает остальное)  смена сети)
```

Стратегии берутся из трёх мест: `general*.bat` оригинального zapret-discord-youtube, готовых стратегий NORMA и ваших собственных.
Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/STRATEGIES.md](docs/STRATEGIES.md).

| 9 | Дополнительно: `service.bat` zapret, игровой фильтр, обновления и IPSet, очистка (драйвер, TCP timestamps), папки |

## Что измеряет бенчмарк

Бенчмарк проверяет, открываются ли нужные сайты, насколько это стабильно (три прогона) и за какое время отвечают серверы.
Скорость самого видеопотока он не измеряет: она задаётся провайдером и Google, а не выбранной стратегией, и снаружи браузера её надёжно не получить.
Если несколько стратегий проходят проверки одинаково, они считаются равными, и NORMA берёт ту, что раньше в списке (тонкие стратегии для YouTube идут первыми).

## Что считается «открывается»

Сайт считается доступным, если получен настоящий ответ сервера. Сертификат при этом проверяется, поэтому подменить ответ по дороге нельзя.
Код ответа показывается, если он не 2xx: многие корни сервисов отвечают 404, это значит «соединение есть». Блокировкой считается отсутствие ответа (сброс, таймаут).

## Свои настройки

| Что | Где |
|---|---|
| Свои домены для обхода | `vendor/zapret/lists/list-general-user.txt` (по одному в строке) |
| Исключения | `vendor/zapret/lists/list-exclude-user.txt` |
| Свои сайты для проверки | `data/targets.user.txt`, строки вида `МойСайт = "https://example.com"` |
| Свои стратегии | `strategies/user/*.args` или `*.bat` (образец: `example.args.sample`) |

## Структура репозитория

```
NORMA.bat            запуск (права администратора)
app/                 код: меню, подбор, сторож, Доктор, фон; app/native: экспериментальный движок на C#
strategies/          norma/ (создаются генератором), user/ (ваши)
vendor/zapret/       оригинальный zapret-discord-youtube без изменений
data/                создаётся при работе: состояние, журналы
docs/                документация
tools/               gen_strategies.py, selftest.ps1
```

## Если что-то не работает

1. Пункт **6 (Доктор)** покажет конфликты (старый `winws`, служба zapret, VPN), недостающие файлы (антивирус мог удалить WinDivert), подмену DNS.
2. Если подбор ничего не нашёл: включите Secure DNS, отключите VPN на время проверки, попробуйте бенчмарк и профиль «YouTube + Discord».
3. Антивирус может ругаться на WinDivert (драйвер перехвата пакетов): это штатно для zapret, добавьте папку в исключения.
4. Telegram блокируется по IP-адресам, обходом пакетов это не лечится.
5. Создайте [issue](https://github.com/Quancore21/NORMA/issues/new/choose) и приложите отчёт Доктора.

Игровой фильтр zapret по умолчанию выключен (меню 9 → 6). Журналы лежат в `data/logs`.

## Отказ от ответственности

NORMA изменяет только сетевой трафик вашего компьютера (перехват пакетов драйвером WinDivert). Вы сами отвечаете за то, чтобы использование
соответствовало законам вашей страны, правилам провайдера и сервисов. Программа поставляется «как есть», без гарантий.
